    How it works

    It reads signatures, not minds

    AI coding tools sign their work: a Co-authored-by trailer, a bot author, a marker in the message. git-abv knows how dozens of tools sign, and counts the commits that carry a signature.

    A floor, not a verdict

    Autocomplete and pasted chat answers leave no trace, and signatures can be switched off. The real number is at least this high. It says nothing about quality.

    Nothing leaves your machine

    The CLI reads your local git history and makes no network requests at all. This page talks to the public GitHub API from your browser, and to nothing else.

    Get the real number

    By lines of code, across the whole history, on any repo. Private ones included.

    npx git-abv

    Zero dependencies. Works on GitHub, GitLab, Bitbucket and that server under someone's desk.

    Hit the rate limit? Use a token

    Without a token GitHub allows 60 API requests an hour. A fine-grained token with read-only access to public repositories is enough. It is kept in this tab only and sent to api.github.com, nowhere else.
